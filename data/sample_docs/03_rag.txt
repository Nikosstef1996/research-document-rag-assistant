Retrieval-augmented generation, abbreviated RAG, combines information retrieval with a language model. First, relevant source documents are loaded and divided into chunks. An embedding model converts text into numeric vectors. The system retrieves chunks that are similar to a user's question using vector similarity search, potentially with keyword matching or reranking. Later, a language model uses selected passages as context to compose an answer. Source metadata such as filename and page number makes citations possible. A high similarity score does not guarantee that a passage is correct or that it answers the question. Evaluation should measure retrieval relevance, groundedness, and whether generated answers are supported by the documents. Retrieved instructions from untrusted documents should not override the application's safety rules.
