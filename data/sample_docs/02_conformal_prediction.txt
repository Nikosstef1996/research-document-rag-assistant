Conformal prediction adds prediction intervals or sets to machine learning predictions. For regression, split conformal prediction uses an independent calibration set to measure how far actual outcomes tend to be from model predictions. A quantile of calibration residuals determines how wide prediction intervals should be. Under exchangeability and the standard split conformal assumptions, these intervals provide finite-sample marginal coverage guarantees. Time-series observations often violate exchangeability, so naive split conformal guarantees should not be assumed to hold for hourly electricity data. Rolling calibration, specialized time-series methods, and backtesting can be useful, but empirical interval coverage must be measured honestly. Evaluate both the fraction of true outcomes covered and the average width of intervals.
